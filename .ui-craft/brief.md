# Project Brief

## Design Intent

A calm, focused enterprise knowledge tool — no noise, no decoration, just clarity. Dense with information but never cluttered. Every pixel serves retrieval accuracy or answer trust.

## Audience

Software engineers and technical teams on desktop. They want density and information, not marketing. They evaluate answers by source citations, not by pretty charts.

## Voice and Tone

Direct and honest. No marketing fluff. Errors explain the root cause. Status messages are terse. Labels use sentence case.

## Constraints

- Dark mode uses pure neutral grey (no blue tint) — Open WebUI style.
- Must support both light and dark themes via shadcn/ui CSS variables.
- Tailwind CSS + shadcn/ui component library.
- No external design system beyond shadcn/ui tokens.
